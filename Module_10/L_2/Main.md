# Домашнее задание к занятию «Кеширование Redis/memcached»

### Задание 1. Кеширование 

Приведите примеры проблем, которые может решить кеширование. 

*Приведите ответ в свободной форме.*

#### Решение:  

1. Высокая нагрузка на базу данных (БД)  

При большом потоке одинаковых запросов к реляционной БД (например, PostgreSQL или MySQL) сервер начинает тратить много ресурсов на обработку SQL-запросов и чтение с диска.  

Решение через кеш:  
Данные (например, каталог товаров или профиль пользователя) сохраняются в оперативной памяти (Redis/Memcached). Повторные запросы забираются из кеша мгновенно, снижая нагрузку на основную БД.  

2. Медленный отклик приложения (High Latency)  

Если для формирования страницы или ответа API приложению нужно выполнить сложные математические расчеты, тяжелые SQL-запросы с множеством JOIN-ов или запросить данные у сторонних сервисов, пользователь будет долго ждать загрузки.  

Решение через кеш:  
Результат один раз рассчитывается и сохраняется в кеш. Последующие пользователи получают готовый ответ за считанные миллисекунды.  

3. Избыточный сетевой трафик и зависимость от сторонних API  

Если приложение зависит от внешних сервисов (например, курсы валют, прогноз погоды или API службы доставки), частые запросы к ним могут привести к исчерпанию лимитов (Rate Limiting), замедлению работы или финансовым затратам.  

Решение через кеш:  
Данные из внешнего API сохраняются в кеш на определенное время (например, на 1 час). Приложение работает независимо от стабильности чужого сервера.  

4. Неэффективное использование ресурсов серверов (Overprovisioning)

Без кеширования в моменты пиковых нагрузок (например, во время распродаж или маркетинговых акций) веб-серверам и серверам приложений приходится постоянно дублировать одну и ту же работу, что требует покупки более мощного и дорогого оборудования.  

Решение через кеш:  
Кеш позволяет пережить «наплыв» пользователей с минимальными затратами серверных мощностей, так как чтение из оперативной памяти требует в разы меньше процессора (CPU), чем генерация динамического контента.  

5. Доступность данных при кратковременных сбоях (Fault Tolerance)

Если основная база данных на короткое время уходит на перезагрузку или испытывает технические трудности, приложение может полностью перестать работать для пользователей.  

Решение через кеш:  
Популярный контент (главная страница, статьи, популярные товары) продолжает отдаваться из кеша, благодаря чему пользователи даже не замечают сбоя в работе основной БД.

### Задание 3. Удаление по TTL в Memcached

Запишите в memcached несколько ключей с любыми именами и значениями, для которых выставлен TTL 5. 

*Приведите скриншот, на котором видно, что спустя 5 секунд ключи удалились из базы.*

#### Решение:  

```
Подключение к Memcached:
telnet localhost 11211

Запись ключей с TTL = 5 секунд:
set key1 0 5 4
test
set key2 0 5 4
test

Проверка работы условия ttl=5:
get key1
get key2

Выход:
quit
```

### Задание 4. Запись данных в Redis

Запишите в Redis несколько ключей с любыми именами и значениями. 

*Через redis-cli достаньте все записанные ключи и значения из базы, приведите скриншот этой операции.*

#### Решение:   

Команда запуска:  

```
docker run --name my-redis -d -p 6379:6379 redis
```

<img width="1502" height="404" alt="image" src="https://github.com/user-attachments/assets/ad8fa34d-b3b1-4d0d-abb4-d99d95a797d0" />  

```
Заходим в контейнер под:
docker exec -it -u 0 my-redis redis-cli

Запись ключей и значений:
SET user:1 "Ivan"
SET user:2 "Anna"
SET status "active"

Получение всех ключей и значений:
KEYS *
MGET user:1 user:2 status

Выход:
exit
```

### Задание 5*. Работа с числами 

Запишите в Redis ключ key5 со значением типа "int" равным числу 5. Увеличьте его на 5, чтобы в итоге в значении лежало число 10.  

*Приведите скриншот, где будут проделаны все операции и будет видно, что значение key5 стало равно 10.*

#### Решение:  

```
Заходим в контейнер под:
docker exec -it -u 0 my-redis redis-cli

Запись ключей и значений:
SET key5 5

Получение значения:
GET key5

Увеличение значения на 5:
INCRBY key5 5

Выход:
exit
```
